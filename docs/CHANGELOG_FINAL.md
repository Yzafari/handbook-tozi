# تغییرات ممیزی تکمیلی

- رفع ارجاع متغیرهای تعریف‌نشده در workerهای استخراج PDF و OCR؛ استخراج صفحه‌به‌صفحه و fallback OCR اضافه شد.
- heartbeat و جداسازی worker ایندکس و OCR اضافه شد؛ رفتار reindex هنگام job فعال ایمن‌تر شد.
- همگام‌سازی آفلاین با hash درخواست و تشخیص reuse نادرست operation ID تقویت شد.
- بازیابی نشست موبایل بعد از بازگشت اتصال اصلاح شد و اجرای تکراری OCR sync حذف شد.
- دانلود آفلاین سند اتمیک‌تر شد، اندازهٔ فایل کنترل می‌شود و سقف cache اسناد/جست‌وجو/تاریخچه محاسبات اضافه شد.
- محدودکنندهٔ نرخ درخواست با Redis مشترک و fallback محلی اضافه شد.
- قرارداد قیمت و پرداخت، idempotency پرداخت، callback redirect و callback موفق دیررس اصلاح شد.
- کنترل امضای واقعی فایل آواتار، مسیر UPLOAD_DIR و پاک‌سازی امن فایل قبلی اصلاح شد.
- مبالغ تاریخی نامشخص در داشبورد درآمد جدا شدند.
- خطاهای body parser به ۴۰۰/۴۱۳ نگاشت شدند.
- بکاپ فایل و دیتابیس با snapshot موقت و checksum امن‌تر شد.
- کوکی‌های refresh و CSRF دارای SameSite قابل تنظیم شدند.
- فهرست شرکت‌های توزیع و یادداشت‌های مربوط به شرکت‌های مستقل شهری/استانی مستندسازی شد.
- آزمون‌های جدید برای استخراج PDF و rate limit store افزوده شد.
