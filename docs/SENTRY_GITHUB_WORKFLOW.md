# گردش‌کار Sentry و GitHub برای هندبوک توزیع

## وضعیت فعلی

- در اجرای فعلی، `SENTRY_AUTH_TOKEN`، `SENTRY_ORG` و `SENTRY_PROJECT` تنظیم نبودند؛ بنابراین هیچ Issue/Event واقعی از Sentry خوانده نشده است.
- فهرست مخازن قابل دسترس GitHub خالی برگشت؛ بنابراین branch یا PR ساخته نشده است.
- کد فعلی در نسخهٔ کاری جداگانه اصلاح و آزمون شده است؛ هیچ تغییری به شاخهٔ اصلی یا محیط تولید منتقل نشده است.

## اتصال امن Sentry

1. در Sentry یک Auth Token فقط‌خواندنی بسازید: https://sentry.io/settings/account/api/auth-tokens/
2. حداقل scopeهای موردنیاز برای ممیزی: `project:read`, `event:read`, `org:read`.
3. این متغیرها را در محیط اجرای محلی/سرور تنظیم کنید: `SENTRY_AUTH_TOKEN`, `SENTRY_ORG`, `SENTRY_PROJECT`.
4. توکن را در چت، فایل ZIP، Git یا screenshot قرار ندهید. توکن API برای خواندن رخدادها با DSN لازم برای SDK اپلیکیشن یکسان نیست.
5. پس از اتصال، پروژه‌های Backend و Mobile به‌صورت جداگانه شناسایی و خطاهای واقعی به تفکیک release/environment بررسی شوند.

## اتصال GitHub و حدود اختیار

- برای ادامهٔ branch/PR باید مخزن دقیق پروژه (owner/repository یا URL) در دسترس اتصال GitHub باشد.
- مجاز در گردش‌کار توسعه: تحلیل، ویرایش کد در branch جداگانه، اجرای تست، ثبت commit و ایجاد Pull Request.
- نیازمند تأیید صریح کاربر: merge به شاخهٔ اصلی، انتشار، تغییرات destructive دیتابیس، حذف دادهٔ کاربران یا اجرای migration روی دیتابیس واقعی.
- تا دریافت دسترسی مخزن، بستهٔ محلی نسخهٔ کاری مرجع باقی می‌ماند.
