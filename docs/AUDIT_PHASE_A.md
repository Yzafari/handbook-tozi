# گزارش ممیزی و تغییرات — بسته A

## دامنه
ZIP ورودی شامل ۱۳۵ فایل بود. این بسته روی بک‌اند Node/Express، Schema و Migrationهای Prisma، و ارتباط پنل React با API فعلی کار کرده است. پروژه موبایل در ZIP ورودی وجود نداشت؛ یک هسته اولیه موبایل جداگانه در این بسته اضافه شده است.

## اصلاح‌های انجام‌شده
- نقش امنیتی `SUPER_ADMIN` به Enum دیتابیس و Constants اضافه شد.
- نقش‌ها در Middleware به‌صورت canonical uppercase بررسی می‌شوند.
- شناسه‌های User/Plan/Payment به‌عنوان String در Validator و Service پردازش می‌شوند.
- فیلدهای موردنیاز User، Payment و Notification با Migration افزایشی اضافه شدند.
- مبلغ تاریخی Payment از ستون قبلی `amount` به `amountToman` منتقل می‌شود.
- وضعیت موفق پرداخت در منطق بک‌اند با Enum موجود `SUCCESS` یکسان شد.
- وضعیت انقضای طبیعی اشتراک `EXPIRED` و لغو دستی `CANCELED` تفکیک شد.
- Admin Service بر اساس مدل‌های واقعی Prisma بازنویسی محدود شد؛ توابع Controller و Service هم‌نام/هم‌قرارداد شدند.
- خروجی فهرست‌های Admin شامل `items` و `meta` شد.
- آمار و نمودار درآمد با شکل مورد انتظار پنل وب هماهنگ شدند.
- مسیرهای پنل برای دریافت درآمد، جزئیات و ویرایش کاربر با بک‌اند همسان شدند.
- مسیرهای ثبت‌نام، ورود و تغییر رمز عبور اعتبارسنجی می‌شوند.
- مسیر CSRF با نام کوکی `gh_csrf` و درخواست GET پنل همسان شد؛ توکن CSRF فقط از Header پذیرفته می‌شود.
- Refresh قدیمی وب نیز CSRF را بررسی می‌کند؛ API موبایل از قرارداد stateless جدا استفاده می‌کند.
- مسیر موبایل `/api/v1/auth/*` افزوده شد و Refresh Token را فقط برای کلاینت موبایل در بدنه پاسخ می‌دهد.
- قفل حساب با مقادیر پیش‌فرض امن فعال شد.
- ثبت‌نام شماره همراه را رمزگذاری می‌کند؛ کلید AES از hex به Buffer 32 بایتی تبدیل می‌شود.
- ایمیل از متغیرهای محیطی استفاده می‌کند؛ اطلاعات Gmail ثابت حذف شد.
- Seed دیگر رمز مدیر ثابت و ناامن ندارد؛ مدیر ارشد فقط با متغیرهای محیطی ساخته می‌شود.
- فایل `.env` از بسته خروجی حذف و `.env.example` جایگزین شد.
- Module Registry صریح برای جلوگیری از فعال‌شدن تصادفی ماژول‌ها اضافه شد.
- تست runner به Node Test Runner تغییر کرد و تست‌های پایه رجیستری اضافه شدند.

## مواردی که هنوز تأیید اجرایی نشده‌اند
- نصب وابستگی‌ها و اجرای واقعی سرور انجام نشده؛ در محیط ساخت، `node_modules` موجود نبود.
- Prisma CLI در محیط حاضر نصب نبود؛ بنابراین `prisma validate` و `prisma generate` اجرا نشدند.
- Migration روی یک کپی واقعی PostgreSQL اجرا نشده است.
- اتصال واقعی زرین‌پال، SMTP، Redis و Object Storage آزمایش نشده است.
- اجرای مرورگر/پنل و تست E2E انجام نشده است.
- APIهای جستجو، OCR، همگام‌سازی، پرداخت قبض و ماژول‌های تخصصی هنوز پیاده‌سازی نشده‌اند.

## هشدار مهاجرت
پیش از اعمال Migration روی محیط عملیاتی، از PostgreSQL نسخه پشتیبان تهیه شود و Migration ابتدا روی Clone دیتابیس اجرا شود. مقدار `amountToman` از `amount` کپی می‌شود؛ صحت واحد پول داده‌های قبلی باید با سوابق واقعی پرداخت تطبیق داده شود.

## امنیت
فایل `.env` ورودی در بسته خروجی وجود ندارد. اگر مقادیر آن کلید واقعی یا رمز سرویس بوده‌اند، آن‌ها را در سرویس مربوطه تعویض کنید. فایل `.env.example` فقط الگو است و قابل استفاده مستقیم در Production نیست.

## نتایج آزمون‌های قابل اجرا در محیط فعلی
- `node scripts/check-project.js`: موفق؛ ۵۶ فایل JavaScript بک‌اند از نظر Syntax بررسی شد.
- `node --test tests/*.test.js`: موفق؛ ۳ تست رجیستری ماژول اجرا شد.
- بررسی مسیر importهای نسبی بک‌اند: صفر مسیر مفقود.
- بررسی Syntax فایل‌های JavaScript سادهٔ فرانت‌اند: ۱۴ فایل، بدون خطا.
- اعتبارسنجی JSON فایل‌های package و app: موفق.
- Build فایل‌های JSX/TSX، تست Vitest فرانت‌اند، TypeScript موبایل و اعتبارسنجی Prisma به‌دلیل نبود وابستگی‌های نصب‌شده در محیط اجرا نشده‌اند.
- آزمون قدیمی `subscription.service.test.js` از Vitest استفاده می‌کرد، اما بک‌اند Vitest را به‌عنوان وابستگی نداشت و قراردادهای تست با مدل فعلی اشتراک هم‌خوان نبود؛ بنابراین از مسیر اجرایی حذف شد تا به‌اشتباه تست معتبر تلقی نشود. پوشش آزمون سرویس اشتراک باید پس از آماده‌شدن محیط تست دیتابیس اضافه شود.
